# Bug ticket template (ticket.md)

Every bug ticket must have exactly these parts, in this order:

    Title: <short summary>
    Severity: <S1|S2|S3|S4>
    ### Impact
    <who is affected and how>
    ### Repro
    <numbered steps>
    ### Evidence
    <the relevant log lines, quoted>

Severity guide: S1 = data loss or outage for all users; S2 = a core feature broken for many
users; S3 = a feature broken with a workaround; S4 = cosmetic.
